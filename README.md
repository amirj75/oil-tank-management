# نسخه آنلاین سامانه مدیریت مخازن روغن

این نسخه برای اتصال به Supabase و استقرار روی Vercel/Netlify آماده شده است.

## مراحل راه‌اندازی
1. در Supabase یک Project بسازید.
2. فایل `schema.sql` را در SQL Editor اجرا کنید.
3. در Authentication > Users یک کاربر بسازید.
4. در `index.html` این دو مقدار را جایگزین کنید:
   - `YOUR_SUPABASE_URL`
   - `YOUR_SUPABASE_ANON_KEY`
5. فایل `index.html` را روی Vercel یا Netlify منتشر کنید.

اطلاعات موجودی و تمام عملیات در دیتابیس مرکزی ذخیره می‌شود و از موبایل و کامپیوتر مشترک خواهد بود.

نکته: برای نسخه نهایی می‌توان سطح دسترسی مدیر/اپراتور، خروجی Excel، نمودارهای کامل و پشتیبان‌گیری را هم اضافه کرد.
